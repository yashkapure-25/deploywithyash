# 🚀 Yash Kapure – Developer Portfolio

A modern, production-ready developer portfolio showcasing my journey as an **AWS ☁️ & DevOps ⚙️ Engineer**.
This platform highlights my projects, experience, certifications, and technical skills through a **clean, responsive, and interactive UI**.

---

## ✨ Key Highlights

* ⚛️ Built with React, TypeScript, and Tailwind CSS
* 🎬 Smooth animations using Framer Motion
* 📱 Fully responsive across all devices
* 🔍 SEO-friendly & accessible (a11y compliant)
* 🐳 Dockerized for scalable deployment
* 🌐 Served using NGINX for high performance

---

## 🛠 Tech Stack

### 💻 Frontend

* React + Vite ⚡
* TypeScript 🟦
* Tailwind CSS 🎨
* Framer Motion 🎞️

### ⚙️ DevOps & Deployment

* Docker 🐳
* Docker Compose 📦
* NGINX 🌐
* CI/CD Ready 🔄

---

## 📂 Project Structure

* `src/components/` → Reusable UI components 🧩
* `src/constants.tsx` → Centralized data management 📊
* `src/types.ts` → Type definitions 🧾
* `public/` → Static assets & resume 📄

---

## ⚡ Getting Started

```bash
npm install
npm run dev
```

---

## 🐳 Docker Setup

```bash
docker build -t yash-portfolio .
docker-compose up -d
```
